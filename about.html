About This Site

Green Stand is a static website that pulls together the football and basketball you follow — schedules, results and key numbers.

What this site does

Every week it turns scattered match info into one clear view: the fixtures, the results, and the trends behind them. Rather than scrolling dozens of posts, this site tries to tell one thing well — that beyond the score, there are playing styles, data-driven stories, and matches worth watching.

Tech stack

  • Plain HTML + CSS + JavaScript: no frameworks or build tools, so the fundamentals are easy to explain and easy to present in class.
  • Multi-page structure: 5 pages connected by a shared navigation bar.
  • No backend: no server or database needed. Favourites are saved with the browser's own localStorage.
  • Git version control: the whole semester's development is tracked in Git as an auditable commit history.
