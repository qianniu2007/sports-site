关于本站

绿茵看台是一个整理身边足球、篮球赛事信息的静态网站。

这个网站是做什么的

把每周的赛程、赛果和关键数据整理成一个清晰的信息台。比起刷很多条碎片消息，这里更想把一件事讲明白：比分之外，还有球队的风格、数据背后的趋势，和每周值得关注的重点。

（把上面这段换成你自己对网站定位的说明。）

技术栈

  • 纯 HTML + CSS + JavaScript：不用任何框架和构建工具，方便理解原理，也方便课上一步步讲清楚。
  • 多页面结构：共 5 个页面，通过顶部导航互相跳转。
  • 无后端：不需要服务器和数据库。收藏功能用浏览器自带的 localStorage 实现。
  • Git 版本管理：整个学期的开发过程都会用 Git 记录，形成可回溯的提交历史。
